紫電Player

紫電Player は、個人が自分で使うために開発している iPhone 向けの動画視聴アプリです。App Store では配布していません。

YouTube API サービスを利用して、次の機能を提供します。

  • 登録チャンネルの新着動画一覧
  • 動画の検索
  • YouTube 公式の埋め込みプレーヤーでの再生
  • 高評価した動画・再生リストの表示

本アプリは YouTube および Google が提供・承認するものではありません。YouTube のコンテンツは YouTube の埋め込みプレーヤーで再生され、広告や表示は YouTube の仕様に従います。
