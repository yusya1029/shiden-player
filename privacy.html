YTPlayer プライバシーポリシー

最終更新日：2026年9月30日（評価・コメント機能の追加に伴い第2項を改定）

1. YouTube API サービスの利用

本アプリは YouTube API サービスを利用しています。本アプリを利用することで、YouTube 利用規約に同意したものとみなされます。YouTube API サービスを通じて Google が取得する情報は、Google プライバシーポリシーに従って取り扱われます。

2. 取得する情報

利用者が Google アカウントでログインし、アクセスを許可した場合に限り、本アプリは YouTube Data API を通じて次の情報を読み取ります。

  • 利用者の YouTube チャンネルの基本情報
  • 登録チャンネルの一覧
  • 高評価した動画の一覧
  • 利用者の再生リスト

要求する権限は、YouTubeアカウントの閲覧（youtube.readonly）です。利用者が動画の評価またはコメントの投稿を初めて行うときに限り、YouTubeアカウントの管理（youtube.force-ssl）の許可を追加で求めます。この権限は、利用者自身が操作したときに、動画の評価（高評価・低評価・取り消し）と、コメントの投稿・編集・削除を行うためだけに使います。本アプリが自動で評価や投稿をすることはありません。表示したコメントは端末に保存しません。

3. 端末内に保存する情報

  • ログイン状態を保つための認証トークン：iOS のキーチェーンに暗号化して保存します。
  • アプリの設定、アプリ内で再生した動画の履歴、利用者が作成したタグやメモ：端末内にのみ保存します。
  • YouTube API から取得した情報（動画のタイトル、サムネイルなど）：表示を速くするために、一時的に端末内へ保存することがあります。保存期間は最長30日で、30日を超えたものは再取得するか削除します。

4. 情報の送信と共有

本アプリは独自のサーバーを持っていません。上記の情報を開発者や第三者へ送信・販売・共有することはありません。また、広告の配信やアクセス解析のための仕組みも組み込んでいません。

本アプリの通信先は、Google／YouTube のサーバーのみです（ログイン、YouTube Data API、埋め込みプレーヤー、サムネイル画像）。埋め込みプレーヤーでは、YouTube が Cookie などを使用することがあります。その取り扱いは Google プライバシーポリシーに従います。

5. Google API サービスのユーザーデータに関するポリシー

Google API から受け取った情報の使用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

6. 情報の削除とアクセス権の取り消し

  • アプリ内でログアウトすると、認証トークンを端末から削除し、Google 側の許可も取り消します。
  • アプリを削除すると、端末内に保存したすべての情報が削除されます。
  • Google アカウントのセキュリティ設定（サードパーティ製のアプリとサービス）からも、本アプリのアクセス権をいつでも取り消せます。

7. 変更

取得する情報や権限を変更する場合は、このページを更新し、最終更新日を改めます。
